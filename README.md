# My DevSecOps Portfolio

## Project Overview

This is my first personal portfolio website, created as part
of Week 03 of my DevSecOps internship.

The project demonstrates the fundamentals of frontend
development using HTML5.

## Project Structure

```text
portfolio/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## Technologies Used

- HTML5
- CSS3 (planned for Day 02)
- JavaScript (planned for Day 03)
- Visual Studio Code
- Firefox
- Linux Mint

## Website Sections

1. Home
2. About Me
3. Technical Skills
4. Projects
5. Contact Form
6. Footer

## Learning Objectives

- Understand HTML document structure.
- Learn semantic HTML elements.
- Create webpage navigation.
- Display technical skills using lists.
- Organize projects using article elements.
- Create a basic contact form.
- Understand how browsers display HTML.

## How to Run

Open the terminal inside the portfolio directory.

Run:

```bash
firefox index.html
```

Alternatively, open index.html in a web browser.
